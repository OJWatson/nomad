# Extract information from rasters

Extract information from rasters

## Usage

``` r
unpack_pop(iso3c_sf, pop)
```

## Arguments

- iso3c_sf:

  A simple feature shape file to extract for

- pop:

  The pop raster from
  [`get_pop`](https://ojwatson.github.io/nomad/reference/get_pop.md)

## Value

Tibble with list columns of raw extracted values
