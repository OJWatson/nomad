# Get population raster.

Downloads the unconstrained individual countries 2000-2020 UN adjusted
(1km resolution) from the [WorldPop server](https://www.worldpop.org/).

## Usage

``` r
get_pop(iso3c, year)
```

## Arguments

- iso3c:

  ISO3c Code

- year:

  Year of World Pop Survey

## Value

Population raster
